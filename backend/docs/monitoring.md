# Participación docente: primera entrega

Consulta global de plataforma para teacher/admin, sin matrículas, grupos ni propiedad académica. GET /monitoring/activity exige require_content_staff; estudiantes 403, sin token 401. UI /seguimiento enlazada desde navegación docente y valida rol antes de consultar. No expone nombres, correos, UUID de cuentas, respuestas, soluciones ni snapshots.

## Definiciones

- Iniciadas: una fila PasapalabraMatch (local u online) o una GameSession sin shared_match_id. Las dos sesiones online nunca duplican el enfrentamiento. Salas sin iniciar excluidas.
- Finalizadas normales/abandonadas/abiertas: estado y desenlace persistidos del match. Consulta de lectura no invoca reconciliación ni modifica reloj: abierta puede estar pendiente de materializar vencimiento.
- Sesión individual heredada completada: normal; incompleta: UNKNOWN, nunca abandono inferido ni abierta confirmada. Estados no reconocidos son desconocidos.
- Cuentas únicas: user_id distintos de las sesiones registradas pertenecientes a las partidas del filtro. Invitados no son cuentas. Tabla muestra números registrados/invitados del match, sin identidad personal.
- Resultados por formato: número de sesiones registradas y recuentos de AnswerLog correctas/incorrectas. Pendientes compartidas según pending_count guardado. Invitado local excluido de agregados de respuestas, sin atribuirlas al anfitrión. No deduplicar respuestas entre sesiones diferentes. Sin logs antiguos no se reconstruye score en respuestas; se informa cobertura desconocida. Incompletas individuales tienen pendientes desconocidas; completadas con todos los logs tienen cero. No se promedian puntuaciones ni tiempos.

## Filtros y contrato

start/end fechas YYYY-MM-DD, ambos opcionales; días inclusivos Atlantic/Canary convertidos a [inicio00:00, día posterior00:00) UTC, respetando horario estacional. Filtra por creación/inicio, no por fecha de respuesta o cierre. Inicio posterior al fin, fecha máxima final, juego inválido o paginación inválida:422. game ALL/TRIVIAL/PASAPALABRA; skip>=0, limit1..100. Tabla orden inicio descendente y referencia estable; total y agregados siempre de todo el filtro, no solo página. UI20 filas; fechas/juego/página conservados en URL, recarga y volver; enviar filtros reinicia página.

Respuesta: scope platform, timezone, unique_registered, started/normal/abandoned/open/unknown, groups (format/sessions/correct/wrong/pending/unknown_sessions), total/items (key/started/game/format/status/registered/guests). unknown_sessions señala cobertura de pendientes incompleta; los recuentos de respuestas son registros existentes, no reconstruidos.

Sin migraciones: todas las fuentes ya existen. Sin motores/reconciliación/snapshots nuevos. Esta entrega no cubre dificultades frecuentes, exportación, administración ni seguimiento docente completo.

## CSV export

`GET /monitoring/activity.csv?start=YYYY-MM-DD&end=YYYY-MM-DD&game=ALL|TRIVIAL|PASAPALABRA` requires the same teacher/admin permission, inclusive Canary day boundaries and platform scope as `/activity`. It calls that same query/transformation with pagination removed: one row per standalone session or shared match, never per online participant. No response contents, names, emails, solutions or question snapshots are exported. Six columns: reference, Canary start ISO timestamp including UTC offset, readable format, persisted state, registered count and guest count. Unknown states remain unknown and missing values are empty. Format labels match the table; internal codes remain unchanged in JSON/persistence.

At most 10,000 rows, checked against the full result before generating the file. Above the cap: HTTP 422 asking for narrower dates; no partial file. This small bounded synchronous export shares the existing in-memory reporting query (which currently reads all relevant activity); it is not a large-volume analytics pipeline. No server-side permanent files or additional infrastructure. Rows describe stored state at export time; concurrent legitimate activity can change totals since the last screen query, and clocks are not reconciled.

UTF-8 BOM, semicolon delimiter for Spanish spreadsheets, CRLF, Python csv quoting of delimiters/quotes/newlines. Text fields starting with formula prefixes, including after whitespace, are apostrophe-prefixed. Static ASCII attachment filename `biogamed-seguimiento.csv`, `Cache-Control: no-store`, `nosniff`, count header. Empty query yields a header-only file. Client uses the existing Axios bearer interceptor with blob response, never a token URL. The temporary browser blob URL is revoked. Duplicate clicks are locked immediately; failures release the lock for retry. Export uses applied URL filters without page, skip or limit; editing the form disables export until Consultar applies them (or the draft returns to the applied values).

Verification: six backend monitoring tests using isolated in-memory SQLite cover permissions, dates/game filters, online deduplication, local guests, incomplete legacy records, >20 rows, empty output, cap rejection, UTF-8, quoting, missing values and formula hardening. Frontend monitoring/date tests cover applied parameters, dirty filters, missing/failed reports, duplicate clicks and recoverable failure. Types, lint and production build pass. No game suites repeated.

Isolated demo updated at http://localhost:13004/seguimiento (existing teacher account). Verified private database connection biogamed_demo before deployment; no database commands or writes, migrations, accounts or games created. Integrated IAB authenticated view downloaded the actual file: 47 rows versus 20 visible rows, 47 unique references, 9 online matches counted once each, exactly six columns and UTF-8 BOM. Inspected the downloaded file outside the repository. Dirty filters visibly disabled export and restoring applied filters re-enabled it.
