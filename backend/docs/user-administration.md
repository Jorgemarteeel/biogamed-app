# Minimal global user/role administration

Scope: `/administracion/usuarios`, menu entry only for administrators. Search by name/email (literal substring, case-insensitive, bounded/escaped), role filter, stable lower(name)/ID order, 20-row UI pages. URL preserves applied search/role/page. Only ID, name, email, role are returned/displayed; no password/hash/token. No deletion, password management, activation, enrolments or groups.

API: `GET /admin/users?search=&role=student|teacher|admin&skip=0&limit=20` (maximum limit 100). `PATCH /admin/users/{UUID}/role` takes only `{expected_role, role}`. Roles are existing enum values. Explicit confirmation identifies target/name/email/ID and old/new roles; selection alone does not save. No-op role changes create no audit entry. Expected-role mismatch is HTTP 409; self-change forbidden with 403, missing target 404, invalid data 422. Public registration now rejects extra fields including role; it still creates only students. Historical stored addresses are preserved as strings by the admin DTO rather than revalidated/rewritten on role changes.

Every endpoint resolves the authenticated user from current DB state, not the JWT role claim. Mutations acquire a transaction-wide PostgreSQL advisory mutex (702641903), refresh/recheck the actor after waiting, lock the target row, compare expected role and count remaining admins, then write role and RoleChange in the same transaction. All application role writers must use this function/mutex. Self-demotion is forbidden, and the last-admin guard is defensive; concurrent cross-demotions cannot remove every admin. PostgreSQL READ COMMITTED is the tested deployment isolation. SQLite fixtures verify functional rules, not cross-process locking. Administrative updates are rare; global serialization is deliberate, no queue/extra service.

Client: loss of access clears the account table/dialog, announces the error and refreshes the profile menu. Profile menu refreshes on mount/open/focus and a local role-refresh event, even when caller props contain an old role. Mobile table scrolls inside a labelled region with readable column minimums; dialog supports keyboard/Escape/cancel and returns focus to its trigger when available. Confirmation conflicts reload/reset drafts and require a new confirmation. No claim of exhaustive screen-reader or load testing.
